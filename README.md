# ELEK19 DATABASE

**An on-going database project to preserve files and content related to critical human and post-human expressions.**

Made on Oct 13, 2026 · Published on Nov 6, 2026 · Version 1.0

Idea, data collections, designs, and curation by **Aeldari Nasim**.

---

## What is this?

ELEK19 is a hand-curated website that collects and links to media about technology, post-humanism, ethics, war and survival, cyberfeminism, science, and society, etc. 

*It is divided into two main parts:*

1. **An Archive for The Cyborg Citizen**: a reading list on criticial philosophy, cyborg theory, cyberfeminism, and the posthuman, global digital activism, speciecism, transformation in structures, etc.
2. **Pre- and Post-Apocalyptic Optimization Database**: texts and media on ethics, survival, war & "apocalypse", suffering, sentience, and emerging technology, etc.

Content is updated on a monthly basis.

**Preserved content includes:** websites, books, philosophy, software, music, audio, videos, video games, articles, fiction, artworks, and documentaries/films, etc.

**Geograhical focus**: This database tries to be as global as it can be, and provides data in varius languages but tends to focus on the West Asian regions more particularly.

## How it was made

- **Design:** every page was designed by hand in Figma, see the design process (of version 1.0) here: https://www.figma.com/design/1dysonNLxmreoyOMsEQOz8/ELEK19-DATABASE--Version--1.0-.?node-id=0-1&t=KZfyC3pob77N0Qs0-1
- **Code:** plain HTML and CSS (with a little JavaScript on the homepage), written from the Figma designs with the help of an AI assistant (Claude Sonnet 5.5, by Anthropic), then edited and published by me.
- **Content:** the selection, curation, and writing are human-original. No content in the database is generated by AI/LLMs, and the idea is not taken from someone else.
- **Hosting:** deployed with [Vercel](https://vercel.com) on the free tier (hobby plan). Every change committed to this repository is redeployed automatically.

## Running it locally plus the demo

There is nothing to install. Download the repository and open `index.html` in a web browser.
**demo**: https://elek19.vercel.app/
